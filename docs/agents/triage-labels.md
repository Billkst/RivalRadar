# Triage Labels

工程 skills 使用五个 canonical triage role。本仓库采用同名 GitHub 标签：

| Skill role | GitHub label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已充分说明，可交给 agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现或决策 |
| `wontfix` | `wontfix` | 不会处理 |

当 skill 使用角色名称时，应用本表右侧对应的 GitHub label。若仓库以后调整
标签词汇，只修改本文件中的映射，不修改各 skill。
